# One-Line Laugh-Off

A single original joke, delivered by a deterministic Python program, for make.fun's ["One-Line Laugh-Off"](https://make.fun/bounty/u-zkhiel-one-line-laugh-off-714618ae) bounty ($2 in USDC, winner takes all).

`main.py` writes exactly one funny line to `/output/entry.txt` — no setup, no explanation, just the punchline landing cold.

## Run it

```sh
python3 main.py
```

Then read `/output/entry.txt`.
